# Política de Tratamiento de Datos Personales - RK Software S.A.S.

Este repositorio contiene la política pública de tratamiento y protección de datos personales de **RK Software S.A.S.**

La política tiene alcance corporativo y complementa las políticas o avisos específicos que puedan aplicar a productos como **Sendo** y **TalentNow**.

## Archivos

- `index.html`: página pública autocontenida de la política.
- `_config.yml`: metadatos básicos para GitHub Pages/Jekyll.
- `README.md`: documentación del repositorio.

## Configuración antes de publicar

Busca en `index.html` los marcadores `PENDIENTE_CONFIGURAR` y reemplaza:

- `[NIT DE RK SOFTWARE S.A.S.]`
- `[DIRECCIÓN DE RK SOFTWARE S.A.S.]`
- `[CORREO PARA PROTECCIÓN DE DATOS]`
- `[TELÉFONO DE CONTACTO]`

Se recomienda utilizar un correo corporativo dedicado, por ejemplo `protecciondatos@rksoftcol.com`, una vez exista y esté habilitado.

## Publicación con GitHub Pages

1. Crea o utiliza un repositorio público destinado a la política corporativa.
2. Agrega estos archivos en la raíz del repositorio.
3. En GitHub, abre **Settings > Pages**.
4. Selecciona **Deploy from a branch**.
5. Selecciona la rama de publicación (por ejemplo `main`) y la carpeta `/ (root)`.
6. Guarda la configuración y espera a que GitHub publique la página.
7. Utiliza la URL pública generada en formularios, avisos de privacidad y demás canales de RK Software.
